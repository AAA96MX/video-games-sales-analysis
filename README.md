# Análisis de Patrones de Ventas de Videojuegos

## 🎯 Objetivo y Metodología
- **Problema:** Analizar un conjunto histórico de ventas de videojuegos a nivel global para entender el desempeño comercial por región, plataforma y género.
- **Metodología:** Realicé limpieza de valores ausentes, transformación y tipificación de tipos de datos, y cálculo de métricas de ventas regionales mediante scripts de Python.

## 📊 Resultados Clave
- Identifiqué las plataformas y géneros con mayores volúmenes de ventas históricas.
- Evalué mediante pruebas de hipótesis estadísticas la relación entre las reseñas de usuarios/críticos y el desempeño comercial.

## 🛠️ Tecnologías y Librerías
- **Lenguaje:** Python
- **Librerías:** Pandas, Matplotlib, Seaborn
- **Técnicas:** Estadística inferencial y pruebas de hipótesis
